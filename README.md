# МеталлЦехСтрой — сайт

Навесы, заборы и ангары под ключ. Собственное производство в Домодедово.

Сайт с **встроенным визуальным редактором** — тексты, фото, цены и контакты меняются прямо на странице без программиста.

---

## 🚀 Быстрый старт

```bash
npm install     # установить зависимости
npm run dev     # запустить сайт (http://localhost:5173)
```

**Как войти в редактор:** 4 быстрых клика в левом нижнем углу → пароль `admin`

Полная инструкция по установке и публикации — в файле **[SETUP.md](./SETUP.md)**

---

## 📥 Скачать все файлы проекта

```bash
npm run pack
```

Создаст архив **`metallcehstroy-site.zip`** со всеми исходниками (без `node_modules`).

---

## 🛠 Доступные команды

| Команда | Что делает |
|---------|-----------|
| `npm run dev` | Запуск в режиме разработки |
| `npm run build` | Сборка сайта в папку `dist/` |
| `npm run preview` | Просмотр собранного сайта |
| `npm run pack` | Упаковать проект в ZIP-архив |

## ✏️ Редактирование контента

Все правки делаются прямо на сайте через встроенный редактор:

- тексты, заголовки, описания
- фотографии (загрузка с устройства)
- цены и настройки калькулятора
- телефоны, адреса, реквизиты
- новые объекты в фотогалерее
- логотип сайта

Правки сохраняются автоматически. Чтобы сделать их постоянными для всех посетителей — нажмите **«Зафиксировать правки в коде»** и обновите файл `src/data/bakedOverrides.ts`.
